# Strings and bytes

`string.h` is complete. Many of the memory functions are hand-written in assembly, built on
the machine's block instruction, so they are **very** fast.

## Memory

```c
#include "string.h"

void* memcpy(void* dst, const void* src, size_t n);   // no overlap
void* memmove(void* dst, const void* src, size_t n);  // overlap allowed
void* memset(void* dst, int c, size_t n);
int   memcmp(const void* a, const void* b, size_t n);
void* memchr(const void* p, int c, size_t n);
size_t strlen(const char* s);
```

<Callout type="info" title="Memcpy in one instruction">
`memcpy` is literally `mcpy`: the machine copies up to 4 KiB per step, with MMU translation
and memory protection. 4 KiB used to cost ~3300 instructions and now costs ~257. `memmove`
only needs extra work when the ranges overlap.
</Callout>

## Splitting a string

```c
char line[] = "red,green,blue";
char* save = NULL;
for (char* tok = strtok_r(line, ",", &save); tok; tok = strtok_r(NULL, ",", &save))
    printf("- %s\n", tok);
```

<Callout type="warn" title="strtok modifies the string">
`strtok` and `strtok_r` write `\0` into the separators. Pass a copy if you need the
original, or use `strspn`/`strcspn` so nothing is mutated.
</Callout>

## Comparing and copying without overflowing

`strlcpy`/`strlcat` are the safe way to work with fixed-size buffers: they copy at most
`size-1` and always NUL-terminate, and return the length that *would* have been needed, so
you can detect truncation.

```c
char dst[16];
size_t needed = strlcpy(dst, "a very long string", sizeof dst);
if (needed >= sizeof dst)
    puts("it was truncated");
```

## Converting numbers and strings

```c
int  n = atoi("42");
long long g = atoll("9223372036854775807");
float f = strtof("3.14", NULL);       // correctly rounded

char buf[32];
itoa(255, buf, 16);                   // "ff"
sprintf(buf, "%d items", 7);          // the formatted way
ftoa(3.14159f, buf, 2);               // "3.14"
ftoa_shortest(buf, sizeof buf, x);    // the fewest digits that read back x
```

## An example: trimming a list

```c
#include "stdio.h"
#include "string.h"
#include "ctype.h"

static void trim(char* s)
{
    size_t n = strlen(s);
    while (n > 0 && isspace((unsigned char)s[n - 1]))
        s[--n] = '\0';
}

int main(void)
{
    char text[] = "  hello,   world  ";
    trim(text);
    printf("[%s]\n", text);          // [  hello,   world]
    return 0;
}
```
