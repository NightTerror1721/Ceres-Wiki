# Cheat sheet

The whole API on one page. Standard C headers and `ceres/` modules.

## Getting started

| I want… | Use | Page |
|---|---|---|
| To build and run | `ceresc prog.c libceres.car --decls … -I include -O2 --run` | Installing |
| To request an optional module | `// USE: irq` / `// USE: fault` / `// USE: mmu` | Installing |
| A 64-bit `double` | `--soft-double` | The software double |
| Debugging with names | `--symtab` | Backtrace |

## Console

| Function | Note |
|---|---|
| `puts/putstr/putchar` | Write |
| `printf/sprintf/snprintf` | Format: `%d %u %o %x %X %b %c %s %p %f %e %g %a %n %%` |
| `getchar/getchar_nb` | Read (blocking / non-blocking) |
| `scanf/sscanf/fscanf` | Formatted input |
| `line_read/line_prompt` | A whole line |
| `read_int/read_float/read_yes_no/read_choice` | Guided input |
| `ansi_goto/ansi_fg/ansi_bg/ansi_clear` | Colour and cursor |
| `fopen/fclose/fread/fwrite/fgets/getline` | Streams (disk, `host:`, memory) |

## Data structures (`ceres/ds/`)

| I need… | Structure |
|---|---|
| A growing array | `vector` |
| Both ends | `deque` |
| LIFO / FIFO | `stack` / `pqueue` |
| An intrusive list | `list` / `slist` |
| ISR → loop | `ringbuf` / `cqueue` |
| Key→value hash | `hashmap` / `gmap` |
| Ordered | `omap` / `oset` / `rbtree` / `skiplist` |
| A static table | `flatmap` / `flatset` |
| Multiple values | `multimap` |
| A cache | `lru` |
| Stable handles | `slotmap` |
| Prefixes | `trie` |
| Groups | `dsu` |
| Bits / membership | `bitset` / `bloom` |
| A growing string | `strbuf` |
