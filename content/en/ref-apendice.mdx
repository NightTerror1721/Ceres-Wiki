# Appendix: devices

The machine's memory-mapped I/O (CeresASM plan/v2 SPEC 5). Every device register is **32
bits** wide and is read and written **only** with aligned 32-bit accesses — `mmio_r32()` /
`mmio_w32()` in `ceres.h`. A byte or halfword access to a register is a fault (`MmioWidth`).
A slot with no device reads all ones and discards writes.

## Slots

256 slots of 64 KiB, from `0xFF000000`, grouped by device class:

| Base | Slot | Device | Header |
| --- | --- | --- | --- |
| `0xFF000000` | `0x00` | Virtual terminal | `ceres/terminal.h` |
| `0xFF010000` | `0x01` | Timer | `ceres/timer.h` |
| `0xFF020000` | `0x02` | DMA | `ceres/dma.h` |
| `0xFF030000` | `0x03` | Debug log | `ceres/debug.h` |
| `0xFF100000` | `0x10` | Keyboard | `ceres/keyboard.h` |
| `0xFF110000` | `0x11` | Mouse | `ceres/mouse.h` |
| `0xFF120000` | `0x12` | Gamepad | `ceres/gamepad.h` |
| `0xFF200000` | `0x20–0x23` | Audio (control, voices, sequencer, streams) | `ceres/audio.h` |
| `0xFF300000` | `0x30` | Disk | `ceres/disk.h` |
| `0xFF310000` | `0x31` | HostFs | `ceres/hostfs.h` |
| `0xFF320000` | `0x32` | Peripheral ports | `ceres/periph.h` |
| `0xFF400000` | `0x40–0x43` | GPU (core/screen, commands, 2D/vector, 3D) | `ceres/video.h` |
| `0xFFFF0000` | `0xFF` | System control | `ceres/sys.h` |

The other slots are reserved. The per-device register tables live in each device's page.

## Physical memory map

| Range | Size | Region | Out of range |
| --- | --- | --- | --- |
| `0x00000000–0x7FFFFFFF` | up to 2 GiB | RAM | `OutOfRam` |
| `0x80000000–0x9FFFFFFF` | 512 MiB | empty | `Unmapped` |
| `0xA0000000–0xDFFFFFFF` | up to 1 GiB | VRAM | `OutOfVram` |
| `0xE0000000–0xFEFFFFFF` | 496 MiB | empty | `Unmapped` |
| `0xFF000000–0xFFFFFFFF` | 16 MiB | MMIO | see the slots |

Fixed RAM: null page `0x000`, BIOS `0x100`, program from `0x400`, and a 4 KiB system stack at
the top of RAM (`sp` starts at `RamSize`).

## System control (`0xFFFF0000`)

| Offset | Register |
| --- | --- |
| `0x00` | Command: write (1 off, 2 reset, 3 load and run) \| `status << 8` |
| `0x04` | RAM size |
| `0x08` | Features (b0 div-fault, b1 IEEE divide) |
| `0x0C` | Stack limit |
| `0x10` / `0x14` | Last fault address / access |
| `0x18` / `0x1C` / `0x20` | argc / argv / envp |
| `0x24` | CPU clock (Hz) |
| `0x28` | Profile id |
| `0x2C` | Fault reason |
| `0x30` / `0x34` | Load path / load args (command 3) |
| `0x38` | VRAM size |

## Interrupts

Exceptions are always deliverable; device interrupts are masked until `sti`.

| # | Name | # | Name |
| --- | --- | --- | --- |
| 1 | Trap | 16 | Timer (countdown) |
| 2 | IllegalInstruction | 17 | Timer (alarm) |
| 3 | MemoryFault | 18 | DMA done |
| 4 | DivisionByZero | 19 | Terminal input / Ctrl+C |
| 5 | StackOverflow | 20 | Keyboard |
| 6 | AlignmentFault | 21 | Mouse |
| 7 | PageFault | 22 | Gamepad |
| 15 | Syscall | 24 / 25 / 26 | Disk / HostFs / Peripherals |
| | | 28 / 29 / 30 | Audio voice / sequencer / stream |
| | | 32 / 33 / 34 / 35 | GPU VBlank / line / copy / fault |

The `IRQ_*` names live in `interrupts.h`; `ceres/irq.h` dispatches them to handlers attached
at run time.

## Registers and ABI

| Registers | Use |
| --- | --- |
| `r0`–`r3` | integer arguments / return value |
| `f0`–`f3` | float arguments / return value |
| `r4`–`r7`, `r12` | volatile (the callee may clobber them) |
| `r8`–`r11`, `f8`–`f15` | preserved by the callee |
| `r13` (`at`) | assembler scratch: **do not use** |
| `r14` (`fp`), `r15` (`sp`) | frame pointer and stack pointer |

`long long`/`double` travel in **register pairs** (`x0`–`x6`, `d0`–`d7`). See `CeresASM
docs/24` and `Ceres-C docs/01` for the full convention.
