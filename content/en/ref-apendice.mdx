# Appendix: devices

Memory map of the MMIO devices. Everything is read and written with a **volatile** access of
the correct width (`ceres.h` gives `mmio_r8/16/32` and `mmio_w8/16/32`). A slot with no device
reads all ones and discards writes.

|---|---|---|---|
| `0xFF000000` | 0 | Terminal | `ceres/terminal.h` |
| `0xFF010000` | 1 | Timer | `ceres/timer.h` |
| `0xFF020000` | 2 | Disk | `ceres/disk.h` |
| `0xFF030000` | 3 | Text framebuffer | `ceres/textfb.h` |
| `0xFF040000` | 4 | DMA | `ceres/dma.h` |
| `0xFF050000` | 5 | Keyboard | `ceres/keyboard.h` |

## RAM map

| Address | What lives there |
|---|---|
| `0x00000000` | Vector table (64 × 4 B) |
| `0x00000100` | BIOS (768 B) |
| `0x00000400` | Your program starts |
| … | Heap ↑ and stack ↓ |
| end of RAM − 4096 | System stack |
| `0xFF000000` + | Devices |

## Terminal (`0xFF000000`)

| Offset | Register |
|---|---|
| `0x00` | Status (bit0 input, bit1 output, bit2 EOF) |
| `0x04` | Output (byte) |
| `0x08` | Input (byte) |
| `0x0C` | Bytes available |
| `0x16`/`0x18` | Mode (raw/keys) |
| `0x1C` | Error output |
| `0xF0/F4/F8` | Block (address/length/command) |

## Timer (`0xFF010000`)

| Offset | Register |
|---|---|
| `0x00` | Ticks (low); latches the high word |
| `0x04` | Wall clock (seconds since 1970) |
| `0x08` | Timer command (arm/periodic) |
| `0x0C` | Milliseconds |
| `0x10/0x14` | Nanoseconds low/high |
| `0x18` | Clock resolution |
| `0x1C` | Halt clock (ticks/s) |
| `0x20/0x24` | Alarm (low/high); writing the high arms it |
| `0x28` | Ticks high |

## Display (`0xFF070000`)

| Offset | Register |
|---|---|
| `0x00` | Command (1 clear, 2 present) |
| `0x04/0x08` | Width / height |
| `0x0C` | Data (one pixel) |
| `0x10` | Mode (0 RGB32, 1 indexed) |
| `0x14/0x18` | Palette index/data |
| `0x1C/0x20` | Scroll X / Y |
| `0xF0/F4/F8` | Pixel block |

## Text framebuffer (`0xFF030000`)

| Offset | Register |
|---|---|
| `0x00` | Command (1 clear, 2 present) |
| `0x04/0x08` | Columns / rows (max 200 × 100) |
| `0x0C` | Cell (character | attribute << 8) |
| `0x10/0x14` | Mode / current output |
| `0xF0/F4/F8` | Block (cells or attributes) |

## Audio (`0xFF090000`)

Single voice: `0x00` status, `0x04` frequency, `0x08` duration, `0x0C` volume, `0x10`
waveform, `0x14` command.

Four channels: commands at `0x20`, status at `0x24`, channel count at `0x28`, and each
channel from `0x40 + n*0x20` (frequency, volume, waveform, duty, attack, decay, sustain,
release).

## Blitter (`0xFF0C0000`)

Command, destination and its stride, source and its stride, width, height, colour/key, scale,
palette, control, status, pixels written.

## System control (`0xFFFF0000`)

| Offset | Register |
|---|---|
| `0x00` | Command (1 shutdown, 2 reset) | `status << 8` |
| `0x04` | RAM size |
| `0x08` | Features (bit0 div-fault, bit1 IEEE div) |
| `0x0C` | Stack limit (R/W) |
| `0x10/0x14` | Last fault address/access |
| `0x18/0x1C/0x20` | argc / argv / envp |

## Interrupts

| No. | Name | No. | Name |
|---|---|---|---|
| 1 | Trap | 17 | Terminal |
| 2 | IllegalInstruction | 18 | DMA |
| 3 | MemoryFault | 19 | Keyboard |
| 4 | DivisionByZero | 20 | Mouse |
| 5 | StackOverflow | 21 | Gamepad |
| 6 | AlignmentFault | 22 | Audio |
| 7 | PageFault | 23 | Periph |
| 16 | Timer | 24 | Alarm |

## Registers and calling convention

| Registers | Use |
|---|---|
| `r0`–`r3` | Integer / pointer arguments |
| `f0`–`f3` | Float arguments |
| `r0` / `f0` | Return value |
| `r4`–`r7`, `r12` | Volatile (the callee may clobber them) |
| `r8`–`r11`, `f8`–`f15` | Preserved by the callee |
| `r13` (`at`) | Assembler scratch: **do not rely on it** |
| `r14` (`fp`), `r15` (`sp`) | Frame and stack |

You do not need to touch the MMIO registers by hand: the `ceres/` headers wrap them in
comfortable functions. This appendix is for when you want to understand what is underneath
or squeeze out something the layer does not expose.
</Callout>
