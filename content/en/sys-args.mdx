# Arguments and environment

Your program can receive arguments and environment variables, like any console program.

## `main` with arguments

```c
#include "stdio.h"

int main(int argc, char** argv, char** envp)
{
    printf("program: %s\n", argv[0]);
    for (int i = 1; i < argc; i++)
        printf("  arg %d: %s\n", i, argv[i]);

    for (int i = 0; envp[i]; i++)
        printf("  env: %s\n", envp[i]);
    return 0;
}
```

The *loader* places the strings and the pointer arrays on the stack and leaves `argc`, `argv`
and `envp` in `r0`/`r1`/`r2`. `argv[argc]` and the last `envp` entry are `NULL`.

## Passing arguments

```shell
> ceresc prog.c libceres.car --decls ... -I include --run -- hello world
> ceres run prog.cres --env MODE=debug --env SOUND=off -- -v level1
```

- Everything **after `--`** belongs to the program.
- `argv[0]` is always the program's path.
- `--env NAME=value` defines the environment (the host's environment is **not** inherited).

## Querying them from anywhere

You do not need to pass `argc`/`argv`/`envp` everywhere: `ceres/sys.h` gives them at any
point.

```c
#include "ceres/sys.h"

int    n = sys_argc();
char** v = sys_argv();
char** e = sys_envp();
```

And `stdlib.h` brings a real `getenv`:

```c
#include "stdlib.h"

const char* mode = getenv("MODE");          // NULL if not defined
if (mode && mode[0] == 'd') debug = 1;

setenv("SCORE", "1200", 1);                 // 1 = overwrite
unsetenv("MODE");
```

<Callout type="info" title="getenv does not touch errno">
`getenv` scans the *loader*'s environment directly and sets no `errno`; a name with `=` or an
empty one is never found. `setenv`/`unsetenv` make a copy on demand (with `malloc`) so they
can modify the environment without touching the loader's.
</Callout>

## A simple option parser

```c
#include "string.h"
#include "stdlib.h"
#include "stdio.h"

int main(int argc, char** argv)
{
    int verbose = 0;
    const char* file = NULL;

    for (int i = 1; i < argc; i++)
    {
        if (strcmp(argv[i], "-v") == 0)         verbose = 1;
        else if (strcmp(argv[i], "-h") == 0)  { puts("usage: prog [-v] file"); return 0; }
        else                                    file = argv[i];
    }

    if (!file) { puts("missing file"); return 1; }
    if (verbose) printf("loading %s\n", file);
    return 0;
}
```

<Callout type="tip" title="Configuration: environment, INI or arguments">
For a game, combine: arguments for the specific (`--level 3`), an **INI** file for persisted
settings, and environment variables for development (`MODE=debug`). Read about
`ceres/ini.h`.
</Callout>
