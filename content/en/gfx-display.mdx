# Pixel display

The **bitmap plane** (`ceres/fb.h`) is an RGB32 pixel picture (`0x00RRGGBB`), up to the
profile's largest (1280×720), behind the text plane. It is **double buffered**: you draw into
the back buffer, `fb_present()` swaps at the next vertical blank and waits for it, so a frame
is never shown half drawn. Full reference: [ceres/fb.h](/wiki/api-fb).

## The basics

```c
#include "ceres/fb.h"

if (fb_init(320, 200) != 0)   // 0 ok, -1 if refused
    return 1;
fb_clear(0x00000000);         // paint the back buffer black
fb_present();                 // swap and wait for the VBlank
```

`fb_width()` / `fb_height()` read the size; `fb_shutdown()` turns the plane off.

## Send a whole frame

```c
unsigned int* pixels = /* w*h words, 0x00RRGGBB */;
fb_blit(pixels);              // a whole picture from RAM, through the copy engine
fb_present();
```

<Callout type="info" title="Vertical blank, or you keep the pace">
`fb_present()` waits for the **vertical blank**, so frames never tear. The pace is set by how
long you take to build each frame; with `--speed realtime` a second of machine time is a
second.
</Callout>

## Indexed mode, palettes and scrolling

Two "retro" touches: a pixel is **one byte** (an index into a palette), and a shift moves what
is shown without redrawing.

```c
fb_init_indexed(320, 200);          // a byte a pixel

unsigned int palette[256];
for (int i = 0; i < 256; i++)
    palette[i] = color_hsv(i * 360 / 256, 255, 255);
fb_load_palette(palette, 256);

unsigned char indices[320 * 200];
/* ... fill ... */
fb_blit(indices);
fb_present();

fb_scroll(5, 0);                    // the picture moves 5 px left, modulo the size
```

<Callout type="tip" title="Why it matters">
Indexed mode uses **a quarter** of the memory and, by changing one palette entry, you change
the colour of every pixel that uses it at once.
</Callout>

## How `gfx` uses it

For comfortable drawing (lines, circles, sprites), use **`gfx`**, which keeps a surface in RAM
and sends it in one go for you:

```c
#include "ceres/gfx.h"

gfx_init(320, 200);
for (;;) {
    gfx_clear(COL_BLACK);
    gfx_circle_fill(160, 100, 20, COL_RED);
    gfx_present();
}
```

We cover it in depth in **2D drawing with gfx**.
