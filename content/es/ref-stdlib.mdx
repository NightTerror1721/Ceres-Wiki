# Referencia: la librería estándar

La **STDLIB de Ceres** es toda la librería C más la API `ceres/` de la máquina. Cada cabecera
abre con un comentario que dice para qué sirve; el propio `tools/gendocs.js` de la STDLIB los
convierte en `docs/reference/`, una página por cabecera, así la referencia no se desincroniza
del código.

Este índice lista **todas** las cabeceras, agrupadas en la librería C y los extras `ceres/`, con
la primera frase de su descripción. El generador la lee directamente de las cabeceras
(`tools/gen/gen-stdlib-index.mjs`).

<Callout type="info" title="Cómo leer esto">
Las páginas narrativas de esta wiki (las secciones *Librería estándar*, *La API de Ceres*,
*Gráficos* y *Sistema*) explican y ponen ejemplos. Esta página es el **mapa exhaustivo**: si una
cabecera existe, está aquí.
</Callout>
