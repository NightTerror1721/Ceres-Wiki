# Argumentos y entorno

Tu programa puede recibir argumentos y variables de entorno, como cualquier programa de
consola.

## `main` con argumentos

```c
#include "stdio.h"

int main(int argc, char** argv, char** envp)
{
    printf("programa: %s\n", argv[0]);
    for (int i = 1; i < argc; i++)
        printf("  arg %d: %s\n", i, argv[i]);

    for (int i = 0; envp[i]; i++)
        printf("  env: %s\n", envp[i]);
    return 0;
}
```

El *loader* coloca las cadenas y los arrays de punteros en la pila y deja en `r0`/`r1`/`r2`
el `argc`, el `argv` y el `envp`. `argv[argc]` y la última entrada de `envp` son `NULL`.

## Pasar argumentos

```shell
> ceresc prog.c libceres.car --decls ... -I include --run -- hola mundo
> ceres run prog.cres --env MODO=debug --env SONIDO=off -- -v nivel1
```

- Todo lo que va **después de `--`** es del programa.
- `argv[0]` es siempre la ruta del programa.
- `--env NOMBRE=valor` define el entorno (el entorno del anfitrión **no** se hereda).

## Consultarlos desde cualquier sitio

No necesitas pasar `argc`/`argv`/`envp` a todo el mundo: `ceres/sys.h` los da en cualquier
punto.

```c
#include "ceres/sys.h"

int    n = sys_argc();
char** v = sys_argv();
char** e = sys_envp();
```

Y `stdlib.h` trae `getenv` de verdad:

```c
#include "stdlib.h"

const char* modo = getenv("MODO");          // NULL si no esta definida
if (modo && modo[0] == 'd') debug = 1;

setenv("PUNTOS", "1200", 1);                // 1 = sobrescribe
unsetenv("MODO");
```

<Callout type="info" title="getenv no toca errno">
`getenv` recorre el entorno del *loader* directamente y no pone `errno`; un nombre con `=`
o vacío nunca se encuentra. `setenv`/`unsetenv` hacen una copia bajo demanda (con `malloc`)
para poder modificar el entorno sin tocar el del cargador.
</Callout>

## Un parser de opciones sencillo

```c
#include "string.h"
#include "stdlib.h"
#include "stdio.h"

int main(int argc, char** argv)
{
    int verboso = 0;
    const char* archivo = NULL;

    for (int i = 1; i < argc; i++)
    {
        if (strcmp(argv[i], "-v") == 0)         verboso = 1;
        else if (strcmp(argv[i], "-h") == 0)  { puts("uso: prog [-v] archivo"); return 0; }
        else                                    archivo = argv[i];
    }

    if (!archivo) { puts("falta el archivo"); return 1; }
    if (verboso) printf("cargando %s\n", archivo);
    return 0;
}
```

<Callout type="tip" title="Configuración: entorno, INI o argumentos">
Para un juego, combina: argumentos para lo puntual (`--nivel 3`), un fichero **INI** para
los ajustes persistidos, y variables de entorno para el desarrollo (`MODO=debug`). Lee
sobre `ceres/ini.h`.
</Callout>
