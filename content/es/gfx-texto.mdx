# Framebuffer de texto

El **framebuffer de texto** es una rejilla de caracteres que tu programa dibuja y luego
muestra. No es una consola que hace scroll: es un tablero que se redibuja entero, ideal
para juegos de texto, roguelikes y menús.

## Iniciarlo

```c
#include "ceres/text.h"

if (text_init(40, 20) != 0)     // columnas, filas (hasta 200x100)
{
    puts("no hay pantalla");
    return 1;
}
text_shutdown();
```

## Dibujar

```c
text_clear(' ');                 // llena la rejilla
text_put(x, y, '@');             // una celda
text_text(x, y, "Hola ñandú");   // UTF-8; '\n' baja una fila
text_printf(x, y, "HP %d", hp);  // con formato
text_hline(x, y, len, '-');
text_vline(x, y, len, '|');
text_rect(x, y, w, h, '#');      // contorno
text_fill(x, y, w, h, '.');
text_box(x, y, w, h);            // marco con + - |
text_copy(dx, dy, sx, sy, w, h); // copia de region
text_scroll(1);                  // sube una fila
text_present();                  // muestra el fotograma
```

## Color por celda

Cada celda tiene un atributo de color (un byte). `0` significa los colores del terminal.

```c
text_set_attr(TEXT_ATTR(TEXT_BRIGHT + TEXT_YELLOW, TEXT_BLACK));
text_text(1, 1, "Título");

text_put_attr(10, 10, '@', TEXT_ATTR(TEXT_WHITE, TEXT_BLUE));   // una celda propia
unsigned char a = text_get_attr(10, 10);
```

Colores: `TEXT_BLACK TEXT_RED TEXT_GREEN TEXT_YELLOW TEXT_BLUE TEXT_MAGENTA TEXT_CYAN TEXT_WHITE`, más
`TEXT_BRIGHT` para sumar brillo. `TEXT_ATTR(fg, bg)` los empaqueta.

## ¿Dónde se ve el fotograma?

El plano siempre lo dibuja la **GPU** (el plano de texto de V0). Con ventana (SDL) lo ves en
pantalla; sin ella (`--headless`) se sigue componiendo y el host puede capturarlo:

```bash
ceres run rogue.cres --headless --screen-log frames.txt   # el plano como texto en cada Present
ceres run rogue.cres --frames shots/                      # un PNG por fotograma
```

El tamaño de la rejilla se consulta en caliente:

```c
int cols = text_cols();
int rows = text_rows();
```

## Un ejemplo: un roguelike mínimo

```c title="rogue.c"
// USE: irq
#include "stdio.h"
#include "ceres/text.h"
#include "ceres/key.h"
#include "ceres/rand.h"

#define W 40
#define H 20

static char mapa[H][W];
static int px = W / 2, py = H / 2;

static void generar(void)
{
    struct rng r;
    rng_seed(&r, 1234);
    for (int y = 0; y < H; y++)
        for (int x = 0; x < W; x++)
            mapa[y][x] = (x == 0 || y == 0 || x == W - 1 || y == H - 1)
                       ? '#' : (rng_chance(&r, 12) ? '#' : '.');
    mapa[py][px] = '.';
}

static void dibujar(void)
{
    for (int y = 0; y < H; y++)
        for (int x = 0; x < W; x++)
            text_put(x, y, mapa[y][x]);
    text_put(px, py, '@');
    text_printf(0, 0, "pos %d,%d", px, py);
    text_present();
}

int main(void)
{
    if (text_init(W, H) != 0) return 1;
    generar();
    key_start();
    for (;;)
    {
        dibujar();
        int k = key_wait();
        if (k == KEYC_ESC || k == 'q') break;
        int nx = px, ny = py;
        if (k == KEYC_UP || k == 'w')    ny--;
        if (k == KEYC_DOWN || k == 's')  ny++;
        if (k == KEYC_LEFT || k == 'a')  nx--;
        if (k == KEYC_RIGHT || k == 'd') nx++;
        if (mapa[ny][nx] != '#') { px = nx; py = ny; }
    }
    key_stop();
    text_shutdown();
    return 0;
}
```

<Callout type="tip" title="El framebuffer y las teclas">
En una ventana las teclas llegan por el dispositivo de teclado; en un terminal, la primera
llamada a `key_start()` pide al anfitrión que las entregue al pulsarlas. El módulo **`irq`**
no es necesario para `key_wait()`: bloquea en el dispositivo.
</Callout>
