# Cadenas y bytes

`string.h` es completo. Buena parte de las funciones de memoria están escritas a mano en
ensamblador, a golpe de instrucción de bloque, así que son **muy** rápidas.

## Memoria

```c
#include "string.h"

void* memcpy(void* dst, const void* src, size_t n);   // sin solape
void* memmove(void* dst, const void* src, size_t n);  // con solape
void* memset(void* dst, int c, size_t n);
int   memcmp(const void* a, const void* b, size_t n);
void* memchr(const void* p, int c, size_t n);
size_t strlen(const char* s);
```

<Callout type="info" title="Memcpy en una instrucción">
`memcpy` es literalmente `mcpy`: la máquina copia hasta 4 KiB por paso, con traducción de
MMU y protección de memoria. 4 KiB costaban ~3300 instrucciones antes y ahora ~257.
`memmove` sólo necesita trabajo extra cuando los rangos se solapan.
</Callout>

## Partir una cadena

```c
char linea[] = "rojo,verde,azul";
char* save = NULL;
for (char* tok = strtok_r(linea, ",", &save); tok; tok = strtok_r(NULL, ",", &save))
    printf("- %s\n", tok);
```

<Callout type="warn" title="strtok modifica la cadena">
`strtok` y `strtok_r` escriben `\0` en los separadores. Pasa una copia si necesitas el
original, o usa `strspn`/`strcspn` para no mutar nada.
</Callout>

## Comparar y copiar sin desbordar

`strlcpy`/`strlcat` son la forma segura de trabajar con buffers de tamaño fijo: copian
como mucho `size-1` y siempre terminan en NUL, y devuelven la longitud que *habría* hecho
falta, para detectar el truncamiento.

```c
char destino[16];
size_t necesita = strlcpy(destino, "una cadena muy larga", sizeof destino);
if (necesita >= sizeof destino)
    puts("se truncó");
```

## Convertir números y cadenas

```c
int  n = atoi("42");
long long g = atoll("9223372036854775807");
float f = strtof("3.14", NULL);       // correctamente redondeado

char buf[32];
itoa(255, buf, 16);                   // "ff"
sprintf(buf, "%d items", 7);          // la via con formato
ftoa(3.14159f, buf, 2);               // "3.14"
ftoa_shortest(buf, sizeof buf, x);    // los minimos digitos que releen x
```

## Un ejemplo: normalizar una lista

```c
#include "stdio.h"
#include "string.h"
#include "ctype.h"

static void recortar(char* s)
{
    size_t n = strlen(s);
    while (n > 0 && isspace((unsigned char)s[n - 1]))
        s[--n] = '\0';
}

int main(void)
{
    char texto[] = "  hola,   mundo  ";
    recortar(texto);
    printf("[%s]\n", texto);          // [  hola,   mundo]
    return 0;
}
```
