# Apéndice: dispositivos

La E/S mapeada en memoria de la máquina (CeresASM plan/v2 SPEC 5). Cada registro de
dispositivo es de **32 bits** y se lee y escribe **solo** con accesos de 32 bits alineados —
`mmio_r32()` / `mmio_w32()` de `ceres.h`. Un acceso de byte o media palabra a un registro es
un fallo (`MmioWidth`). Un slot sin dispositivo lee todo unos y descarta las escrituras.

## Slots

256 slots de 64 KiB, desde `0xFF000000`, agrupados por clase de dispositivo:

| Base | Slot | Dispositivo | Cabecera |
| --- | --- | --- | --- |
| `0xFF000000` | `0x00` | Terminal virtual | `ceres/terminal.h` |
| `0xFF010000` | `0x01` | Temporizador | `ceres/timer.h` |
| `0xFF020000` | `0x02` | DMA | `ceres/dma.h` |
| `0xFF030000` | `0x03` | Registro de depuración | `ceres/debug.h` |
| `0xFF100000` | `0x10` | Teclado | `ceres/keyboard.h` |
| `0xFF110000` | `0x11` | Ratón | `ceres/mouse.h` |
| `0xFF120000` | `0x12` | Gamepad | `ceres/gamepad.h` |
| `0xFF200000` | `0x20–0x23` | Audio (control, voces, secuenciador, flujos) | `ceres/audio.h` |
| `0xFF300000` | `0x30` | Disco | `ceres/disk.h` |
| `0xFF310000` | `0x31` | HostFs | `ceres/hostfs.h` |
| `0xFF320000` | `0x32` | Puertos periféricos | `ceres/periph.h` |
| `0xFF400000` | `0x40–0x43` | GPU (núcleo/pantalla, comandos, 2D/vectorial, 3D) | `ceres/video.h` |
| `0xFFFF0000` | `0xFF` | Control del sistema | `ceres/sys.h` |

Los demás slots están reservados. Las tablas de registros de cada dispositivo están en su
página.

## Mapa físico de memoria

| Rango | Tamaño | Región | Fuera de rango |
| --- | --- | --- | --- |
| `0x00000000–0x7FFFFFFF` | hasta 2 GiB | RAM | `OutOfRam` |
| `0x80000000–0x9FFFFFFF` | 512 MiB | vacío | `Unmapped` |
| `0xA0000000–0xDFFFFFFF` | hasta 1 GiB | VRAM | `OutOfVram` |
| `0xE0000000–0xFEFFFFFF` | 496 MiB | vacío | `Unmapped` |
| `0xFF000000–0xFFFFFFFF` | 16 MiB | MMIO | ver los slots |

RAM fija: página nula `0x000`, BIOS `0x100`, programa desde `0x400` y una pila del sistema de
4 KiB en lo alto de la RAM (`sp` arranca en `RamSize`).

## Control del sistema (`0xFFFF0000`)

| Offset | Registro |
| --- | --- |
| `0x00` | Comando: escribir (1 apagar, 2 reset, 3 cargar y ejecutar) \| `status << 8` |
| `0x04` | Tamaño de RAM |
| `0x08` | Características (b0 div-fault, b1 IEEE divide) |
| `0x0C` | Límite de pila |
| `0x10` / `0x14` | Dirección / acceso del último fallo |
| `0x18` / `0x1C` / `0x20` | argc / argv / envp |
| `0x24` | Reloj de CPU (Hz) |
| `0x28` | Perfil |
| `0x2C` | Motivo del fallo |
| `0x30` / `0x34` | Ruta de carga / argumentos de carga (comando 3) |
| `0x38` | Tamaño de VRAM |

## Interrupciones

Las excepciones se entregan siempre; las de dispositivo están enmascaradas hasta `sti`.

| Nº | Nombre | Nº | Nombre |
| --- | --- | --- | --- |
| 1 | Trap | 16 | Timer (cuenta atrás) |
| 2 | IllegalInstruction | 17 | Timer (alarma) |
| 3 | MemoryFault | 18 | DMA terminado |
| 4 | DivisionByZero | 19 | Terminal: entrada / Ctrl+C |
| 5 | StackOverflow | 20 | Teclado |
| 6 | AlignmentFault | 21 | Ratón |
| 7 | PageFault | 22 | Gamepad |
| 15 | Syscall | 24 / 25 / 26 | Disco / HostFs / Periféricos |
| | | 28 / 29 / 30 | Audio: voz / secuenciador / flujo |
| | | 32 / 33 / 34 / 35 | GPU: VBlank / línea / copia / fallo |

Los nombres `IRQ_*` están en `interrupts.h`; `ceres/irq.h` los despacha a manejadores
enganchados en tiempo de ejecución.

## Registros y ABI

| Registros | Uso |
| --- | --- |
| `r0`–`r3` | argumentos enteros / valor de retorno |
| `f0`–`f3` | argumentos flotantes / valor de retorno |
| `r4`–`r7`, `r12` | volátiles (el llamado puede romperlos) |
| `r8`–`r11`, `f8`–`f15` | preservados por el llamado |
| `r13` (`at`) | scratch del ensamblador: **no usar** |
| `r14` (`fp`), `r15` (`sp`) | puntero de marco y de pila |

`long long`/`double` viajan en **pares de registros** (`x0`–`x6`, `d0`–`d7`). Ver `CeresASM
docs/24` y `Ceres-C docs/01` para el convenio completo.
