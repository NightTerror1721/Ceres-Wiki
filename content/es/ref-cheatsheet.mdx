# Chuletario

Toda la API en una página. Cabeceras de C estándar y módulos de `ceres/`.

## Arranque

| Quiero… | Usa | Página |
|---|---|---|
| Compilar y ejecutar | `ceresc prog.c libceres.car --decls … -I include -O2 --run` | Instalar |
| Pedir un módulo opcional | `// USE: irq` / `// USE: fault` / `// USE: mmu` | Instalar |
| `double` de 64 bits | `--soft-double` | El double de software |
| Debug con nombres | `--symtab` | Backtrace |

## Consola

| Función | Nota |
|---|---|
| `puts/putstr/putchar` | Escribir |
| `printf/sprintf/snprintf` | Formato: `%d %u %o %x %X %b %c %s %p %f %e %g %a %n %%` |
| `getchar/getchar_nb` | Leer (con/sin bloqueo) |
| `scanf/sscanf/fscanf` | Entrada con formato |
| `line_read/line_prompt` | Una línea completa |
| `read_int/read_float/read_yes_no/read_choice` | Entrada guiada |
| `ansi_goto/ansi_fg/ansi_bg/ansi_clear` | Color y cursor |
| `fopen/fclose/fread/fwrite/fgets/getline` | Streams (disco, `host:`, memoria) |
