# Sokoban por niveles

Empuja cajas hasta los objetivos. Es el ejemplo perfecto de juego de **puzles por niveles**:
rejilla, reglas simples, niveles como texto y **deshacer**.

<GameDemo kind="sokoban" title="Sokoban">
**Flechas** o **WASD** para mover. **R** reinicia el nivel, **Nivel** pasa al siguiente.
</GameDemo>

## El nivel como texto

La forma más cómoda de escribir puzles: cada carácter es una celda.

| Carácter | Significado |
|---|---|
| `#` | Pared |
| ` ` | Suelo |
| `@` | Jugador |
| `$` | Caja |
| `.` | Objetivo |
| `*` | Caja sobre objetivo |
| `+` | Jugador sobre objetivo |

```c title="sokoban.c (niveles)"
static const char* const niveles[] = {
    "#####",
    "#   #",
    "# $ #",
    "# @ #",
    "#  .#",
    "#####",

    "  ###  ",
    "  #.#  ",
    "### ###",
    "# $@$ #",
    "#  .  #",
    "#######",
};
static const int total_niveles = sizeof niveles / sizeof niveles[0];
```

Para una versión completa, carga los niveles de un fichero con `fgets` o de un **pack de
recursos**. Mira **Streams y ficheros** y **Packs de recursos**.

## El tablero

Separamos lo **estático** (paredes y objetivos) de lo **móvil** (jugador y cajas):
así el dibujado y deshacer son triviales.

```c
#define MAX_ANCHO 32
#define MAX_ALTO 20

static char estatico[MAX_ALTO][MAX_ANCHO];   // '#', '.', ' '
static char movil[MAX_ALTO][MAX_ANCHO];      // '$' o ' '
static int jug_x, jug_y;
static int ancho, alto;
static int movimientos;

{
```

## Las reglas

Empujar requiere que la casilla siguiente esté libre (o sea el hueco de una caja que se
mueve):

```c
static int puede(int x, int y)      // ¿hay suelo y no hay pared?
{
    if (x < 0 || x >= ancho || y < 0 || y >= alto) return 0;
    return estatico[y][x] != '#';
}

static int mover(int dx, int dy)
{
    int nx = jug_x + dx, ny = jug_y + dy;
    if (!puede(nx, ny)) return 0;

    if (movil[ny][nx] == '$')       // hay que empujar
    {
        int bx = nx + dx, by = ny + dy;
        if (!puede(bx, by) || movil[by][bx] == '$') return 0;
        guardar_deshacer();
        movil[ny][nx] = ' ';
        movil[by][bx] = '$';
    }
    else
    {
        guardar_deshacer();
    }

    jug_x = nx; jug_y = ny;
    movimientos++;
    return 1;
}
```

## Deshacer

Una pila de movimientos. Guarda lo mínimo para revertir: la posición y si se movió una caja.

```c
#define MAX_UNDO 256

struct movimiento { int x, y, dx, dy; int empujo; };
static struct movimiento undo[MAX_UNDO];
static int undo_top;

static void guardar_deshacer(void)
{
    if (undo_top >= MAX_UNDO) return;
    /* el movimiento se rellena al llamar a mover; aqui dejamos hueco */
    undo_top++;
}

/* al pulsar U */
static void deshacer(void)
{
    if (undo_top == 0) return;
    undo_top--;
    struct movimiento* m = &undo[undo_top];
    if (m->empujo)
    {
        movil[m->y + m->dy][m->x + m->dx] = ' ';      // la caja vuelve
        movil[m->y][m->x] = '$';
    }
    jug_x = m->x;
    jug_y = m->y;
    movimientos--;
}
```

<Callout type="warn" title="El orden importa">
Rellena el `struct movimiento` **antes** de mover nada: apunta la posición vieja, la
dirección y si iba a empujar. Así deshacer es una simple inversa.
</Callout>

## ¿Nivel resuelto?

Todas las cajas sobre sus objetivos:

```c
static int resuelto(void)
{
    for (int y = 0; y < alto; y++)
        for (int x = 0; x < ancho; x++)
            if (movil[y][x] == '$' && estatico[y][x] != '.')
                return 0;
    return 1;
}
```

## Dibujar

```c
static void dibujar(int nivel, int *top)
{
    fb_clear(' ');
    for (int y = 0; y < alto; y++)
        for (int x = 0; x < ancho; x++)
        {
            unsigned char attr = 0;
            char c = ' ';
            if (estatico[y][x] == '#') { c = '#'; attr = FB_ATTR(FB_WHITE, FB_BLUE); }
            else if (estatico[y][x] == '.') { c = 'o'; attr = FB_ATTR(FB_GREEN, FB_BLACK); }
            if (movil[y][x] == '$')
            {
                c = '@';   // caja
                attr = (estatico[y][x] == '.') ? FB_ATTR(FB_BLACK, FB_GREEN)
                                               : FB_ATTR(FB_BLACK, FB_YELLOW);
            }
            if (x == jug_x && y == jug_y) { c = 'P'; attr = FB_ATTR(FB_WHITE, FB_RED); }
            fb_put_attr(x, y, c, attr);
        }
    fb_printf(0, alto, "Nivel %d  mov %d  U:deshacer  R:reiniciar  N:siguiente",
              nivel + 1, movimientos);
    *top = 0;
    fb_present();
}
```

## El bucle

```c
int main(void)
{
    if (fb_init(24, 12) != 0) return 1;
    int nivel = 0;
    cargar_nivel(nivel);
    key_start();

    for (;;)
    {
        int top = 0;
        dibujar(nivel, &top);
        int k = key_wait();
        if (k == KEYC_ESC || k == 'q') break;

        if (k == 'u')            deshacer();
        else if (k == 'r')       cargar_nivel(nivel);
        else if (k == 'n')     { nivel++; cargar_nivel(nivel); }
        else if (k == KEYC_UP || k == 'w')    mover(0, -1);
        else if (k == KEYC_DOWN || k == 's')  mover(0, 1);
        else if (k == KEYC_LEFT || k == 'a')  mover(-1, 0);
        else if (k == KEYC_RIGHT || k == 'd') mover(1, 0);

        if (resuelto())
        {
            fb_printf(2, alto - 1, "¡RESUELTO! (N siguiente)");
            fb_present();
            key_wait();
            nivel++;
            cargar_nivel(nivel);
        }
    }
    key_stop();
    fb_shutdown();
    return 0;
}
```

## Ideas para seguir

- **Cuenta de pasos y óptimo**: guarda el récord por nivel (un `save`).
- **Reinicio y deshacer ilimitado** con un `stack` de la librería en vez del array.
- **Transiciones**: el mismo motor sirve para otros puzles de rejilla (deslizantes, rayos).
- **Gráficos**: cambia `fb_put_attr` por `tilemap_draw` y tendrás Sokoban en píxeles.
