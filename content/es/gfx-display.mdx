# Pantalla de píxeles

El **plano bitmap** (`ceres/fb.h`) es una imagen de píxeles RGB32 (`0x00RRGGBB`), hasta la
resolución máxima del perfil (1280×720), detrás del plano de texto. Tiene **doble búfer**:
dibujas en el búfer trasero, `fb_present()` intercambia en el siguiente VBlank y espera a él,
así un fotograma nunca se muestra a medias. Referencia completa: [ceres/fb.h](/wiki/api-fb).

## Lo básico

```c
#include "ceres/fb.h"

if (fb_init(320, 200) != 0)   // 0 ok, -1 si se niega
    return 1;
fb_clear(0x00000000);         // pinta el búfer trasero de negro
fb_present();                 // intercambia y espera el VBlank
```

`fb_width()` / `fb_height()` leen el tamaño; `fb_shutdown()` apaga el plano.

## Enviar un fotograma entero

```c
unsigned int* pixeles = /* w*h palabras, 0x00RRGGBB */;
fb_blit(pixeles);             // una imagen entera desde la RAM, por el motor de copia
fb_present();
```

<Callout type="info" title="VBlank, o tú llevas el ritmo">
`fb_present()` espera al **VBlank**, así los fotogramas nunca se rasgan. El ritmo lo pone
cuánto tardas en construir cada fotograma; con `--speed realtime` un segundo de máquina es un
segundo.
</Callout>

## Modo indexado, paletas y scroll

Dos toques "retro": un píxel es **un byte** (un índice a una paleta), y un desplazamiento mueve
lo mostrado sin redibujar.

```c
fb_init_indexed(320, 200);          // un byte por píxel

unsigned int paleta[256];
for (int i = 0; i < 256; i++)
    paleta[i] = color_hsv(i * 360 / 256, 255, 255);
fb_load_palette(paleta, 256);

unsigned char indices[320 * 200];
/* ... rellena ... */
fb_blit(indices);
fb_present();

fb_scroll(5, 0);                    // la imagen se mueve 5 px a la izquierda, módulo el tamaño
```

<Callout type="tip" title="Por qué importa">
El modo indexado usa **un cuarto** de la memoria y, cambiando una entrada de paleta, cambias el
color de todos los píxeles que la usan a la vez.
</Callout>

## Cómo lo usa `gfx`

Para dibujar cómodo (líneas, círculos, sprites), usa **`gfx`**, que guarda una superficie en
RAM y te la envía de una vez:

```c
#include "ceres/gfx.h"

gfx_init(320, 200);
for (;;) {
    gfx_clear(COL_BLACK);
    gfx_circle_fill(160, 100, 20, COL_RED);
    gfx_present();
}
```

Lo cubrimos en profundidad en **Dibujo 2D con gfx**.
