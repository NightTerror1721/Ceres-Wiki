# La CLI de `ceresc`

`ceresc` es el **compilador Ceres-C**: lee C (y fuentes `.casm`) y produce texto CASM o — con
`--run` — ensambla, enlaza y ejecuta el programa en la máquina.

## Invocación

```
ceresc <fichero.c|fichero.casm|fichero.cobj|fichero.car>... [-o <salida>] [opciones]
```

Las entradas son fuentes C (se compilan), fuentes CASM (se ensamblan), objetos `.cobj` y
archivos `.car` (se enlazan tal cual).

## El flujo `--stdlib`

`ceresc prog.c --stdlib -O2 --run` compila contra la librería C donde está instalado Ceres:
`CERES_PATH/stdlib/include` entra en la búsqueda de includes y, con `--run`, se enlaza
`libceres` y `stdlib/lib` entra en la búsqueda de `-l`.

```shell
> ceresc hello.c --stdlib -O2 --run          # compila, enlaza y ejecuta, de una vez
> ceresc hello.c --stdlib -O2 -o hello.cres  # solo enlaza el programa
```

<Callout type="info" title="¿Dónde está Ceres?">
`ceresc` encuentra `ceres` y la librería en `--ceres-path`, luego `CERES_PATH`, luego junto a sí
mismo, luego el `PATH` (para `ceres`). Ver [Instalar un paquete](/wiki/instalar-paquete).
</Callout>

## El pipeline por pasos

Para conservar las piezas, usa `-S` (compilar a CASM) y deja que `ceres` ensamble y enlace:

```shell
> ceresc prog.c --stdlib -I include -O2 -S -o prog.casm
> ceres asm -c prog.casm -o prog.cobj
> ceres link prog.cobj libceres.car -o prog.cres
```

Con el pipeline por pasos, pasa las declaraciones de la librería a `ceresc` (`--decls`) y el
archivo a `ceres link`. Ver [Montar el toolchain](/wiki/build-toolchain).
